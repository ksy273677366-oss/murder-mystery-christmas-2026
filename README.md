# 🎄 머더미스터리 크리스마스 나잇

2026년 12월 12일(토) 저녁 7시 ~ 13일(일) 아침 6시, 홍대 파티룸 ‘한 겨울, 사건의 집’에서 열리는 머더미스터리 파티의 모바일 초대장입니다.

- 초대장: https://ksy273677366-oss.github.io/murder-mystery-christmas-2026/
- 참석 회신: 12월 4일까지, 초대장 하단에서 `이름` + `참석 범위` 선택 후 바로 제출(구글 폼 연동)

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 초대장 본문 (단일 파일, 외부 의존은 Google Fonts뿐) |
| `og-image.png` | 카카오톡·SNS 공유 미리보기 이미지 (1200×630) |
| `make_og.py` | 위 미리보기 이미지를 만드는 스크립트 (선택 사항) |

## 초대장에 들어 있는 기능

- 2026-12-12 19:00(KST) 기준 실시간 D-Day 카운트다운
- 세로 스크롤 타임라인 · 스크롤 등장 애니메이션 · 눈 내리는 배경
- 주소 원터치 복사 / 네이버 지도 열기
- 이름 + 참석 범위 선택 → 구글 폼(`docs.google.com/forms`)으로 바로 제출, 제출 완료 메시지 표시
- OG 메타 태그로 카카오톡 공유 시 미리보기 노출
